Lesson 0004 · Rust · CLI 工具養成路線

迴圈與集合

目標：能用 for 重複處理一批資料，並用 Vec 存放、新增一組動態長度的資料。

前兩課處理了「存單一份資料」跟「依條件分支」。這一課處理「一批資料」—— 任何 CLI 工具讀取一份清單、逐行處理檔案、統計一堆輸入，都需要這兩樣東西：能重複跑的迴圈，跟能裝一堆東西的容器。

for：走訪一個範圍或集合

fn main() {
    for n in 1..=5 {
        println!("n = {}", n);
    }
}

1..=5 是一個「範圍（range）」，包含 1 到 5（含尾）；如果寫 1..5（不含 =），就是 1 到 4，不含 5。for 會自動走訪這個範圍裡的每個值，不需要自己維護計數器。

為什麼優先用 for，不是 while？ Rust 也有 while（條件為真就繼續跑），但走訪固定範圍或集合時，for 不用自己手動加計數器，也不會有「忘了 +1 造成無窮迴圈」這種錯誤。while 留給「不知道要跑幾次、要看某個條件」的情況（例如「一直讀輸入直到使用者按 Ctrl+D」）。

Vec：長度可變的清單

上一課的型別（i32、String...）都只裝一個值。Vec<T>（唸作 "vector"）是最常用的集合型別，裝一串同型別的值，長度可以動態增減： 

fn main() {
    let mut names = Vec::new();
    names.push(String::from("alice"));
    names.push(String::from("bob"));

    for name in &names {
        println!("{}", name);
    }
}
Vec 跟 array 是同一類概念嗎？ 是，兩個都存一串同型別的值，差在長度固不固定。Array（[i32; 3]）長度是型別的一部分，編譯時就固定，不能之後 push/pop；Vec<T> 長度可以動態增減，資料放在 heap 上。寫 CLI 工具時幾乎都用 Vec —— 因為讀進來的檔案有幾行、使用者給了幾個參數，通常是執行時才知道的數量。Array 留給你確定數量永遠固定的情況（例如棋盤座標 [u8; 8]）。
幾個要注意的地方：
  • Vec::new() 建一個空的 vector；因為之後要 push，前面要加 mut。
  • names.push(...) 把值加到尾端。
  • for name in &names 前面的 & 代表「借用（borrow）」—— 只是看一眼裡面的每個元素，不會把 names 拿走、之後 names 還能繼續用。借用的細節之後有專門一課，現在先記得「走訪集合時通常要加 &」。

也可以用簡寫，一次建好初始內容：

let scores = vec![10, 20, 30];
for s in &scores {
    println!("score = {}", s);
}
小測驗：for n in 1..3 { println!("{}", n); } 會印出幾行？（用阿拉伯數字回答，例如「1」）
這一課的成果
你現在能用 for 走訪範圍與 Vec、能用 Vec::new() + push 動態組出一份清單。下一課會進到「讀取使用者輸入」—— 讓程式能真的跟外界互動，這是把前面所有東西串成一個可執行 CLI 工具的關鍵一步。
