Lesson 0001 · Rust · CLI 工具養成路線

Hello, Cargo

目標：能夠獨立用 Cargo 建立一個 Rust 專案、看懂它長什麼樣子、並且執行它。

你之前學過 Rust，但忘得差不多了，所以我們把這次當成完全重新開始 —— 不假設你記得任何東西。這一課只有一個目標：建立、看懂、執行一個 Rust 專案。之後每一課都會疊加在這個基礎上，慢慢往「寫一個真的 CLI 工具」推進。

為什麼從 Cargo 開始，而不是單一 .rs 檔？

你資料夾裡舊的練習（hello_rust/1_helloWorld/main.rs）是直接用 rustc 編譯單一檔案，這在教學範例裡常見，但真正的 CLI 工具幾乎都是「專案」：有相依套件（dependencies）、有多個檔案、需要打包發佈。Cargo 是 Rust 官方的建構工具與套件管理器，從今天起我們一律用它，因為它就是你以後寫真實工具時會用的東西。

動手做

在終端機執行：

cargo new hello_cli
cd hello_cli

Cargo 會幫你建立這樣的結構：

hello_cli/
├── Cargo.toml   ← 專案設定檔（名稱、版本、相依套件）
├── .gitignore
└── src/
    └── main.rs  ← 程式進入點

打開 src/main.rs，你會看到：

fn main() {
    println!("Hello, world!");
}
三個要記住的東西：
  • fn main() — 每個可執行的 Rust 程式都從這個函式開始執行，這是規定，不能改名字。
  • println! 結尾的 ! 代表這是一個巨集（macro），不是一般函式 — 現在只要記得「印東西到終端機用這個」就好，巨集的細節之後再談。
  • 每行結尾的 ; 是必要的陳述式結尾符號。

執行它：

cargo run

你應該會看到 Cargo 先編譯（Compiling hello_cli...），再印出：

Hello, world!

把它改成你自己的

把 main.rs 改成這樣，並再跑一次 cargo run：

fn main() {
    println!("Hello, {}!", "Rust CLI");
}

{} 是格式化字串的佔位符，println! 會把後面的參數依序填進去。這是你以後印出使用者輸入、檔案內容、錯誤訊息時都會用到的模式。

小測驗：如果你把 fn main() 改名成 fn start()，執行 cargo run 會發生什麼事？（用 3 個字回答，例如「會編譯錯」或「正常執行」這種長度）
這一課的成果
你現在能用 cargo new 建立專案、看懂 Cargo.toml / src/main.rs 的角色分工、並用 cargo run 編譯並執行程式。下一課會開始處理「資料」——變數與型別，這是後面讀寫檔案、處理使用者輸入的地基。
