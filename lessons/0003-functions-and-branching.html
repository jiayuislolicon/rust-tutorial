函式與分支

目標：能寫出有參數、有回傳值的函式，並用 if/else 依條件做不同的事。

上一課處理了「存資料」，這一課處理「組織邏輯」。任何 CLI 工具都會需要：把邏輯拆成小函式、依條件走不同分支（例如「檔案存在嗎？」「參數合法嗎？」）。這兩件事是寫任何實際程式的最小骨架。

函式：參數與回傳值

在 hello_cli 裡試試：

fn add(a: i32, b: i32) -> i32 {
    a + b
}

fn main() {
    let sum = add(2, 3);
    println!("sum = {}", sum);
}
三個要注意的地方：
  • 參數一定要標註型別（a: i32），不像變數可以讓編譯器推斷。
  • -> i32 宣告回傳型別。
  • a + b 後面沒有分號 —— 這是函式的回傳值。加上分號會變成陳述式，就沒有回傳值了（回傳 ()，也就是「空」）。
陳述式（statement）指的是只執行一個動作、但本身不產生任何值的一行程式碼；跟它相對的是表達式（expression）——會求值出一個結果的程式碼。判斷方式很機械：看有沒有分號 —— a + b（無分號）是表達式，a + b;（有分號）是陳述式。

如果你習慣其他語言的 return，這裡也可以寫，效果一樣：

fn add(a: i32, b: i32) -> i32 {
    return a + b; // 有 return 就可以加分號
}

兩種寫法都對。慣例上，函式最後一行常省略 return，只在提早返回（例如分支中間跳出）時才用 return。

if / else 是表達式，不只是敘述

先看最基本的形式：

fn main() {
    let attempts = 3;

    if attempts > 5 {
        println!("太多次了");
    } else {
        println!("還可以再試");
    }
}
跟其他語言不一樣的地方： Rust 的 if 是表達式（expression），代表它可以直接產生一個值、賦給變數 —— 不需要三元運算子 ? :： 
let attempts = 3;
let status = if attempts > 5 { "blocked" } else { "ok" };
println!("status = {}", status);

規則跟函式回傳值一樣：每個分支最後一行不能加分號，而且兩個分支的型別必須一致（這裡都是 &str）。少了 else、或兩邊型別不同，就不能拿 if 當表達式用。

小測驗：fn square(n: i32) -> i32 { n * n; } 這樣寫，cargo run 會發生什麼事？（用 3 個字回答，例如「會編譯錯」或「正常執行」這種長度）
