# rust-tutorial

從頭開始學 Rust 的個人教材與練習紀錄，目標是能寫出可實際使用的 CLI 工具與後端服務。

## 目錄結構

- `lessons/` — 依序編號的課程（HTML），從 Hello World 到所有權、借用、字串型別
- `reference/` — 依主題整理的速查參考（cargo、Option/Result、所有權與借用、字串型別）
- `learning-records/` — 學習過程紀錄，追蹤已完成的課程與觀察到的理解狀況
- `hello_cli/` — 練習用的 Cargo 專案
- `GLOSSARY.md` — 本教材使用的專有名詞統一定義
- `MISSION.md` — 學習目標與範圍界定
- `NOTES.md` — 教學風格與內容上的注意事項
- `RESOURCES.md` — 參考資料與延伸閱讀連結

## 使用方式

依照 `lessons/` 內的編號順序閱讀，搭配 `reference/` 查閱細節，`hello_cli/` 用於實作練習。
