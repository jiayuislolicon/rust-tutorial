# Rust Resources

## Knowledge

- [The Rust Programming Language (official book)](https://doc.rust-lang.org/book/)
  The canonical, free, official book. Use for: primary source for every core-language lesson (ownership, structs, enums, error handling, traits, etc.). Chinese translation: https://rust-lang.tw/book-tw/
- [Rust by Example](https://doc.rust-lang.org/rust-by-example/)
  Official, runnable code samples per concept. Use for: quick "show me the syntax" reference alongside a lesson.
- [Rustlings](https://github.com/rust-lang/rustlings)
  Official small-exercises project maintained by the Rust team. Use for: hands-on retrieval practice/exercises per topic, once a concept has been introduced.
- [Command Line Applications in Rust (Rust CLI Book)](https://rust-cli.github.io/book/)
  Official Rust CLI working group's guide. Use for: everything CLI-specific — argument parsing (clap), error handling patterns, packaging/distribution — directly tied to the mission.
- [std library docs](https://doc.rust-lang.org/std/)
  Authoritative API reference. Use for: citing exact behavior of stdlib types (String, Option, Result, Vec, etc.) in lessons.
- [thiserror (docs.rs)](https://docs.rs/thiserror)
  Derive macros for `Display` / `Error` / `From` on custom error enums. Use for: Lesson 39 and any later error-type cleanup.

## Wisdom (Communities)

- [r/rust](https://reddit.com/r/rust)
  Large, high-signal subreddit. Use for: real-world code review, "is this idiomatic" questions, ecosystem crate recommendations.
- [Rust Users Forum](https://users.rust-lang.org/)
  Official community forum, welcoming to beginners. Use for: getting help on specific compiler errors or design questions.
