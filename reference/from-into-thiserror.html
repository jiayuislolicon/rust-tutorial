From / Into 與 thiserror

來自 Lesson 39。 實作 From，免費得到 Into；thiserror 用屬性產生 Display、Error、From。

From 與 Into

impl From<std::io::Error> for AppError {
    fn from(e: std::io::Error) -> AppError {
        AppError::ReadFailed(e)
    }
}

// 上面寫完之後，下面兩行等價：
let a = AppError::from(io_err);
let b: AppError = io_err.into();   // Into 自動存在，不要手寫 impl Into
  • ? 轉發錯誤時會呼叫 From::from。
  • 只實作 From<A> for B；不要同時手寫 Into<B> for A。
  • 自訂錯誤（如 Err(AppError::Empty)）本來就是目標型別，不需要 From。

thiserror

cargo add thiserror
use thiserror::Error;

#[derive(Error, Debug)]
pub enum AppError {
    #[error("讀不到檔案：{0}")]
    ReadFailed(#[from] std::io::Error),

    #[error("空檔案")]
    Empty,

    #[error("未知旗標：{0}")]
    UnknownFlag(String),

    #[error("數字格式錯誤：{0}")]
    BadNumber(#[from] std::num::ParseIntError),
}
屬性作用
#[derive(Error)]產生 Display + std::error::Error
#[error("...")]該變體的顯示訊息；{0}／{field} 插值
#[from]產生 From<欄位型別>（並標記為 source）

跟 anyhow 的分工

  • thiserror：定義有形狀的錯誤 enum（函式庫、可 match 的變體）——這一課用的。
  • anyhow：應用程式裡一個「什麼錯都行」的錯誤型別，著重加 context。兩者常一起出現，但角色不同。
