Cargo 基本指令

專案結構

my_project/
├── Cargo.toml   ← 專案 metadata + 相依套件（dependencies）
├── Cargo.lock   ← 鎖定的相依套件版本（自動產生，通常不手動改）
└── src/
    └── main.rs  ← 二進位 crate 的進入點，含 fn main()

常用指令

cargo new <name>     # 建立新專案
cargo run             # 編譯並執行
cargo build           # 只編譯，不執行（debug 模式）
cargo build --release # 編譯最佳化版本（正式發佈用）
cargo check           # 只檢查能不能編譯，速度較快，不產生執行檔
cargo test            # 執行測試

核心概念

  • Crate：一個編譯單元，二進位（binary）或函式庫（library）。
  • main 函式：二進位 crate 的固定進入點。
  • 巨集（macro）：呼叫時結尾有 !，例如 println!。
