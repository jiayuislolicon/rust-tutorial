String 與 &str

兩者的差別

String        擁有內容、可增長、離開作用域時釋放
&str          借用一段字、不能增長、不擁有任何東西

"字面值"       型別是 &str（編譯時烤進執行檔）

寫函式簽名時選哪個

參數，只要讀      → &str          ← 預設就選這個
參數，需要修改    → &mut String
回傳值            → String
struct 欄位       → String
需要保存下來      → String

三條的理由（都有編譯器擋著）

回傳值不能用 &str
  → 借用的來源是函式裡的區域變數，函式結束就被釋放
  → error[E0515]: cannot return reference to local variable
  → 唯一的路是交出所有權，也就是回傳 String

struct 欄位建議用 String
  → 用 &str 不是不行，但要多標一個 lifetime
  → error[E0106]: missing lifetime specifier
    help: consider introducing a named lifetime parameter
  → String 讓 struct 自己擁有內容，沒有「誰先死」的問題

修改一定要 String
  → &str 上根本沒有 push_str / insert_str / clear
  → error[E0599]: no method named `push_str` found for reference `&str`
  → 這是能力問題，不是權限問題
  → 再加上「不想拿走所有權」→ 所以是 &mut String

為什麼參數要用 &str

fn f(s: &str)      f(&owned)  ✅    f("字面值")  ✅
fn f(s: &String)   f(&owned)  ✅    f("字面值")  ❌

❌ 的訊息：expected `&String`, found `&str`

&str 全收，&String 只收一半。選 &str 沒有代價。
（&String 能當 &str 用是 deref coercion，方向單向。）

互相轉換

// &str → String（配置一塊新記憶體 + 整份複製，字串越長越慢）
"abc".to_string()
"abc".to_owned()
String::from("abc")

// String → &str（只記下位置，資料不動，長度無關）
&s
s.as_str()

切片

let s = String::from("hello world");
&s[0..5]     // "hello" — 不複製，只是指向 s 裡的一段
&s[6..11]    // "world"

切片是借用 → 只要切片還活著，s 就不能被修改。

UTF-8：索引數的是 bytes

let s = String::from("你好世界");

s.len()               // 12  ← bytes，不是字數
s.chars().count()      // 4   ← 字數
&s[0..1]              // 執行時 panic

panic 訊息：
byte index 1 is not a char boundary;
it is inside '你' (bytes 0..3) of `你好世界`

規則：要逐字處理或數字數，一律用 .chars()，不要用索引。
ASCII 以外的字元，索引切片隨時可能 panic。

常用方法

// 兩種型別都有（&str 上的方法 String 也能用）
.len()                 bytes 數
.chars()               逐字元的 iterator
.lines()               逐行的 iterator
.trim()                去頭尾空白 → &str
.split(',')            切開 → iterator of &str
.contains("x")         是否包含
.starts_with("x")      是否開頭是
.to_uppercase()        → String（新配置一份）
.parse::<i32>()        → Result<i32, _>

// 只有 String 有（需要修改 → 需要 &mut）
.push_str("x")         接到尾端
.push('c')             接一個字元
.insert_str(0, "x")    插入到指定位置
.clear()               清空
