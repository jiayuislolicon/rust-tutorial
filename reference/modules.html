mod / pub / use

mod：宣告一個檔案是模組

// main.rs
mod errors;   // 編譯 src/errors.rs
mod report;   // 編譯 src/report.rs

少寫 mod，即使檔案存在，編譯器也當作它不存在。只需要在 一個地方宣告一次（通常是 main.rs）。

pub：預設全部私有，要開放才加

pub struct Report { ... }     // 型別要跨檔案用，struct 本身要 pub
pub fn load_report(...) { ... } // 函式要跨檔案呼叫，也要 pub
enum LineKind { ... }          // 只在同一個檔案內用，維持私有

對照 TypeScript：pub 就是 export。沒 pub 的項目只能在同一個檔案（模組）內使用。

use：把路徑帶進目前的作用域

use errors::AppError;
use report::{Report, load_report};

// 不用每次都寫 report::load_report(...)
let report = load_report(filename)?;

對照 TypeScript：use 就是 import。從專案根目錄算的完整路徑用 crate:: 開頭，例如 crate::errors::AppError。

三者分工：mod 決定「哪些檔案要編譯」，pub 決定「誰能被別的檔案看到」，use 決定「用短名字還是長路徑」。三個問題各自獨立，別混著想。

來源：The Rust Book — Chapter 7（繁中版：rust-lang.tw）。 對應課程：Lesson 19 · 用 mod 拆成多檔案。
