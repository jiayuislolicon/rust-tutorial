錯誤處理與自訂錯誤型別

自訂錯誤型別：一個 enum，一種失敗一個變體

enum AppError {
    ReadFailed(std::io::Error),
    Empty,
}

fn load_report(filename: &str) -> Result<Report, AppError> {
    match std::fs::read_to_string(filename) {
        Err(e) => Err(AppError::ReadFailed(e)),
        Ok(content) if content.trim().is_empty() => Err(AppError::Empty),
        Ok(content) => Ok(Report::new(filename, content)),
    }
}

實作 Display：讓 {} 知道怎麼印

use std::fmt;

impl fmt::Display for AppError {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        match self {
            AppError::ReadFailed(e) => write!(f, "讀不到檔案：{}", e),
            AppError::Empty => write!(f, "檔案是空的"),
        }
    }
}

// 實作完之後：
println!("{}", err);       // 直接可用
let msg = err.to_string();  // 也直接可用
impl Report 是「幫 Report 加方法」；impl fmt::Display for AppError 是「幫 AppError 實作 Display 這個 trait」——多了 for TypeName，因為 trait 是標準函式庫定義好的規格。

呼叫端：一次 match 處理所有失敗原因

match load_report(filename) {
    Ok(report) => println!("{}", report.summary()),
    Err(err) => println!("{}", err),
}
