Cargo 依賴管理

加入依賴

cargo add clap                       # 加入最新版
cargo add clap --features derive     # 加入並開啟 feature
cargo add serde@1.0                  # 指定版本範圍
cargo remove clap                    # 移除依賴

Cargo.toml [dependencies] 語法

[dependencies]
# 簡單寫法——只指定版本
serde = "1.0"

# 完整寫法——需要 feature 時
clap = { version = "4", features = ["derive"] }

# 版本範圍語意（semver）
# "4"       → ≥4.0.0, <5.0.0
# "4.5"     → ≥4.5.0, <5.0.0
# "4.5.23"  → ≥4.5.23, <5.0.0
# "=4.5.23" → 精確鎖定這個版本

Cargo.toml vs Cargo.lock

Cargo.tomlCargo.lock
內容你想要的版本範圍實際使用的精確版本
誰寫的你Cargo 自動產生
要 commit 嗎？永遠要二進位 crate：要；library crate：通常不要

Feature（功能旗標）

# 開啟 feature
clap = { version = "4", features = ["derive"] }

# 開啟多個 feature
serde = { version = "1", features = ["derive", "rc"] }

Feature 是 crate 作者定義的可選功能。沒開啟的 feature 不會被編譯。

常用指令

cargo add <crate>         # 加入依賴
cargo remove <crate>      # 移除依賴
cargo update              # 在 Cargo.toml 的範圍內升級到最新版
cargo tree                # 顯示依賴樹
cargo doc --open          # 產生並打開你的專案 + 所有依賴的文件

查文件

  • docs.rs：https://docs.rs/<crate名稱> — 所有 crates.io 上的 crate 自動產生的 API 文件。
  • crates.io：https://crates.io/crates/<crate名稱> — 下載量、版本歷史、原始碼連結。
  • cargo doc --open：在本地產生你的專案和所有依賴的文件，離線也能看。
