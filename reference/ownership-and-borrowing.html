所有權與借用

三條所有權規則

1. 每一個值都有一個擁有者（owner）
2. 同一時間只能有一個擁有者
3. 擁有者離開作用域時，值就被釋放

兩條借用規則

在任何一個時間點，一個值可以有：

    任意多個 &        （唯讀借用）
  或
    剛好一個 &mut     （可改借用）

兩者不能同時存在。
借用的範圍到「最後一次使用」為止，不是到大括號結尾。

三種傳值方式

fn f(s: String)        // 移動：擁有者變成 s，呼叫端失效
fn f(s: &String)       // 借用：只能讀，呼叫端還能用
fn f(s: &mut String)   // 可改借用：能改，呼叫端還能用

f(text);               // 移動
f(&text);              // 借用
f(&mut text);          // 可改借用（text 必須是 let mut）

複製還是移動？

有 Copy 標記 → 賦值時複製，原變數還能用
沒有        → 賦值時移動，原變數失效

有：  i32 i64 u8 usize / f64 f32 / bool / char / &T
沒有：String / Vec<T> / &mut T

分界線是「大小固定」vs「可以增長」，不是「數字」vs「其他」。

四個錯誤代號

E0382  borrow of moved value
       → 移動之後又用了原變數
       → 修法：改成 &（首選）或 .clone()（會真的複製）

E0502  cannot borrow as mutable because it is also borrowed as immutable
       → & 和 &mut 並存
       → 修法：把讀取移到修改之前，讓借用先結束

E0499  cannot borrow as mutable more than once at a time
       → 兩個 &mut
       → 修法：讓第一個借用結束後再開第二個

E0596  cannot borrow as mutable, as it is not declared as mutable
       → 忘記寫 let mut
       → 修法：照訊息裡的 help 加上 mut

&mut 的三個 mut

fn add_line(s: &mut String) { ... }   // ← 參數型別
let mut text = String::new();         // ← 變數宣告
add_line(&mut text);                  // ← 呼叫處

三個都要寫，少一個就編不過。

為什麼要有這些規則

單一擁有者      → 避免 double free（同一塊記憶體釋放兩次）
& / &mut 互斥   → 避免資料競爭（一邊改，一邊有人在讀）

兩者都在編譯時檢查，所以 Rust 不需要垃圾回收（GC）。

選擇順序

1. 只需要讀           → &
2. 需要改，但不想搬走 → &mut
3. 真的需要擁有       → 直接傳值（移動）
4. 兩邊都要獨立的一份 → .clone()

.clone() 是最後手段。它一定能過，但會真的複製資料。
