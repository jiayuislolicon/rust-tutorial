Serde

來自 Lesson 38。 Serde 是序列化框架；serde_json 是負責 JSON 這種格式的 crate。

加入依賴

cargo add serde --features derive
cargo add serde_json
[dependencies]
serde = { version = "1", features = ["derive"] }
serde_json = "1"

Serialize：Rust 值 → 文字

use serde::Serialize;

#[derive(Serialize)]
struct ReportJson<'a> {
    filename: &'a str,
    lines: usize,
}

let json = ReportJson { filename: "a.rs", lines: 3 };
let text = serde_json::to_string_pretty(&json)?;   // Result<String, _>
// 或 to_string(&json) —— 單行、不縮排

Deserialize：文字 → Rust 值

use serde::Deserialize;

#[derive(Deserialize)]
struct Config {
    min: usize,
}

let cfg: Config = serde_json::from_str(r#"{ "min": 2 }"#)?;

動態 JSON：Value

let value: serde_json::Value = serde_json::from_str(&text)?;
assert_eq!(value["filename"], "a.rs");
assert_eq!(value["lines"], 3);

常用屬性

屬性作用
#[serde(rename = "file_name")]JSON key 與欄位名不同時改名
#[serde(skip)]序列化／反序列化時略過此欄位
#[serde(default)]反序列化缺欄位時用 Default

設計習慣

  • 內部資料模型（如 Report）與輸出形狀不同時，另建 view struct，不要硬把整包序列化。
  • 手拼 JSON 字串無法正確處理跳脫字元與巢狀結構——交給 serde_json。
  • 其他格式：toml、serde_yaml 等，同樣實作 Serialize／Deserialize。
