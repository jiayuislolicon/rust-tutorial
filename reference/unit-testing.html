單元測試：#[test] / assert_eq! / cargo test

標準寫法

// 寫在該檔案（例如 report.rs）最下方

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn some_behavior() {
        assert_eq!(actual_value, expected_value);
    }
}

四個新東西

語法作用
#[test]標記一個函式為測試，cargo test 才會執行它。
#[cfg(test)]只在 cargo test 時編譯這段程式碼；cargo build / run 不含它。
mod tests { use super::*; }把測試放進子模組的慣例寫法，use super::* 引入外層所有項目。
assert_eq!(a, b) / assert!(cond)不符合就 panic，該測試被標記 failed；其他測試照常繼續。

執行

cargo test

依序執行所有 #[test] 函式，印出每個測試 ok / FAILED，最後總結通過與失敗數量。

一個測試 panic 不會讓 cargo test 整體中斷——它會把這個測試標記為 FAILED，繼續跑下一個，最後回報幾個過、幾個沒過。
